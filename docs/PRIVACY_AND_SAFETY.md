# Privacy and Safety

## Principles
1. Local-first storage
2. Explicit consent before any cloud LLM use
3. Encryption in transit and at rest
4. Least-privilege Android permissions, requested only when needed
5. User can export, delete, and wipe all data

## Safety boundaries
- Not a clinician, lawyer, or emergency service
- Gives supportive guidance and checklists only
- If the user may be in danger, show emergency contacts and crisis guidance

## Threats to address
- Lost or stolen phone (app lock, encrypted storage)
- API key leakage (Android Keystore)
- Prompt injection from web content (domain allowlist)
