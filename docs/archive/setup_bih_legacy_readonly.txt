# B.I.H. — Brain Injury Helper

Privacy-first voice + text assistant for daily support, built for people with brain injuries.

## Vision
B.I.H. is a personal AI assistant designed to reduce cognitive load and help with day-to-day life:
- reminders (medication, appointments, tasks)
- routines broken into simple steps
- memory support (voice/text notes + recall)
- paperwork/disability-form guidance
- calm, short, non-judgmental interactions

> **Important:** B.I.H. is not a medical provider and does not replace professional care.

---

## MVP Scope (Android + CLI, single user)

### Included in MVP
1. **Chat (text first, then voice)**
2. **Memory journal** (capture and search notes)
3. **Reminders** (local notifications)
4. **Routines** (checklist style)
5. **Paperwork helper** (guided prompts + export drafts)
6. **Safety mode** (emergency contacts and escalation text)
7. **Provider abstraction** (cloud LLM + local LLM option)

### Deferred (post-MVP)
- Cross-device desktop/laptop app integrations
- Deep app control across all phone/laptop apps
- Wearables integration
- Advanced multimodal OCR ingestion

## Tech Stack

### Why this stack
- **Python FastAPI backend**: easy to learn, fast to iterate, great ecosystem
- **Android app in Kotlin (Jetpack Compose)**: best native Android experience
- **Python CLI**: simple local interface for quick testing and backup access
- **SQLite + SQLCipher-ready design**: local-first, encrypted-at-rest path

### Components
- `apps/android`: Android mobile app (primary interface)
- `apps/cli`: command-line client
- `services/api`: FastAPI server
- `libs/core`: shared domain logic (Python package)
- `docs`: architecture, privacy model, roadmap

---

## Privacy & Security Principles

1. **Local-first by default** for personal data
2. **Least privilege permissions** (only request Android permissions when needed)
3. **Encrypted storage** for sensitive content
4. **Explicit consent** before enabling cloud LLMs
5. **No background data sharing by default**
6. **Clear user controls**: export, delete, and wipe data

See `docs/PRIVACY_AND_SAFETY.md` for details.

# Privacy and Safety Model

## Core Principles
1. Data minimization
2. Explicit consent
3. Local-first storage
4. Encryption in transit and at rest
5. User control over data lifecycle

## Threat Model (Initial)
- Device theft or unauthorized local access
- API key leakage
- Over-permissioned mobile app
- Prompt injection from web content

## Controls
- Biometric/app lock (Android)
- Token/key storage in encrypted keystore
- Domain allowlist for web lookup tools
- Output filtering for legal/medical overconfidence
- Per-feature permission prompts

## LLM Provider Strategy
- Default: cloud provider with strict privacy commitments
- Optional: local model runtime (no cloud transmission)
- User sees and approves provider mode in Settings

## Safety Boundaries
- Not emergency service
- Not a clinician/lawyer
- Provides supportive guidance and checklists
- Escalates to emergency actions when risk is detected

## Data Lifecycle
- Export all data (JSON + text)
- Delete selected records
- Full local wipe

from fastapi import FastAPI
from pydantic import BaseModel
from typing import Literal

app = FastAPI(title="BIH API", version="0.1.0")


class ChatRequest(BaseModel):
    message: str
    mode: Literal["supportive", "concise"] = "supportive"


class ChatResponse(BaseModel):
    reply: str


@app.get("/health")
def health():
    return {"status": "ok"}


@app.post("/chat", response_model=ChatResponse)
def chat(req: ChatRequest):
    # Placeholder response; real provider wiring in next step.
    prefix = "I hear you. " if req.mode == "supportive" else ""
    return ChatResponse(reply=f"{prefix}You said: {req.message}")
EOF

import httpx

API_URL = "http://127.0.0.1:8000"


def main():
    print("B.I.H CLI (type 'exit' to quit)")
    while True:
        msg = input("You: ").strip()
        if msg.lower() in {"exit", "quit"}:
            print("Take care. Goodbye.")
            break
        try:
            r = httpx.post(f"{API_URL}/chat", json={"message": msg, "mode": "supportive"}, timeout=20)
            r.raise_for_status()
            print("B.I.H:", r.json().get("reply", ""))
        except Exception as e:
            print("Error:", e)


if __name__ == "__main__":
    main()
EOF
